# Varo Crown Pack

Minecraft Resource Pack für das Pinguin Netzwerk (Fabiderpinguin.de). Fügt dem Varo-Plugin eine 3D-Krone hinzu, die der Gewinner der letzten Runde in der nächsten Runde trägt.

Wird automatisch an Spieler beim Betreten des Varo-Servers ausgeliefert (`Player#setResourcePack`) - kein manueller Download nötig.

Aktuelle Pack-Datei: siehe [Releases](../../releases).
